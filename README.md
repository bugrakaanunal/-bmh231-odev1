# BMH231 Ödev 1 - Sunucu Projesi
**Amacı:** Node.js, Git ve npm kullanılarak oluşturulmuş temel bir HTTP web sunucusudur.

## Kurulum ve Çalıştırma
1. `git clone <senin-github-repo-linkin>`
2. `cd bmh231-odev1`
3. `npm install`
4. `npm start`

## Desteklenen Yollar
- `/` : Ana sayfa
- `/hakkimda` : Hakkımda sayfası
- `/api/ders` : Ders bilgileri (JSON)
- `/api/agep` : Kalan gün hesabı (JSON)
